🔗 Website Integration — How to Connect
When user clicks "Play Aviator" on your website, call this from your PHP backend:
// Step 1: Create a session for the user (call from your PHP backend) // Replace AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION with your actual secret $response = file_get_contents('http://localhost:3050/api/session/create', false, stream_context_create([ 'http' => [ 'method' => 'POST', 'header' => 'Content-Type: application/json', 'content' => json_encode([ 'apiSecret' => 'AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION', 'userId' => $user->id, // your user's ID 'username' => $user->name, // display name 'balance' => $user->balance, // current wallet balance ]) ] ])); $data = json_decode($response, true); // Step 2: Redirect user to the game header('Location: ' . $data['gameUrl']); // Step 3: When user comes back, sync balance back to your DB $sync = file_get_contents('http://localhost:3050/api/session/sync', false, stream_context_create([ 'http' => ['method' => 'POST', 'header' => 'Content-Type: application/json', 'content' => json_encode(['apiSecret' => 'AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION', 'userId' => $user->id])] ])); $balance = json_decode($sync, true)['currentBalance']; // Update $user->balance = $balance in your DB
Express.js / Node.js integration example:
// On your website server (Express.js) const axios = require('axios'); const AVIATOR_URL = 'http://localhost:3050'; const API_SECRET = 'AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION'; // Route: GET /play-aviator (user clicks "Play" on your website) app.get('/play-aviator', async (req, res) => { const user = req.session.user; // your auth session const { data } = await axios.post(`${AVIATOR_URL}/api/session/create`, { apiSecret: API_SECRET, userId: user.id, username: user.name, balance: user.wallet_balance }); res.redirect(data.gameUrl); // redirect to game with token }); // Route: GET /aviator-callback (user returns from game) app.get('/aviator-callback', async (req, res) => { const user = req.session.user; const { data } = await axios.post(`${AVIATOR_URL}/api/session/sync`, { apiSecret: API_SECRET, userId: user.id }); // Update DB with new balance await db.users.update({ id: user.id }, { wallet_balance: data.currentBalance }); res.redirect('/dashboard'); });
Python / Flask / Django integration:
# Flask Example import requests AVIATOR_URL = "http://localhost:3050" API_SECRET = "AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION" @app.route("/play-aviator") def play_aviator(): user = current_user # your logged-in user resp = requests.post(f"{AVIATOR_URL}/api/session/create", json={ "apiSecret": API_SECRET, "userId": str(user.id), "username": user.display_name, "balance": float(user.wallet_balance) }) game_url = resp.json()["gameUrl"] return redirect(game_url) @app.route("/aviator-callback") def aviator_callback(): user = current_user sync = requests.post(f"{AVIATOR_URL}/api/session/sync", json={ "apiSecret": API_SECRET, "userId": str(user.id) }).json() user.wallet_balance = sync["currentBalance"] db.session.commit() return redirect("/dashboard")
⚠️ Production Note: The API secret AVIATORX_API_SECRET_CHANGE_THIS_IN_PRODUCTION must be changed in server.js before going live. Never expose it in frontend code. Always call the session API from your server-side backend only.
